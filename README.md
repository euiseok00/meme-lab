# 🧪 메시지 실험실

> 친구에게 메시지를 **"아주 진지하게"** 전달하는 장난 웹서비스

👉 **바로 사용하기: https://meme-lab-khaki.vercel.app**

링크를 연 친구는 연구소의 검증 절차를 통과해야 메시지를 볼 수 있어요.
마지막엔 반전이 있습니다. 😎

---

## ✉️ 보내는 사람

1. [사이트](https://meme-lab-khaki.vercel.app)에 접속합니다.
2. 전달할 메시지를 입력합니다. **(최대 40자)**
3. 공유 방법을 고릅니다.
   - **카카오톡으로 공유하기**: 카톡 친구에게 바로 보내기
   - **링크 생성하기**: 링크를 복사해 어디든 보내기

## 📩 받는 사람

1. 받은 링크를 엽니다.
2. **검증 시작하기**를 누릅니다.
3. **클릭** 버튼을 **7번** 누릅니다.
4. 검증이 끝나면 친구의 메시지가 화면 가운데에 나타납니다.
5. 나도 보내고 싶다면 **나도 만들기**를 누르세요.

---

## ⚠️ 주의

- 메시지는 **링크 안에 그대로 담깁니다.** 링크를 가진 사람은 누구나 볼 수 있어요.
  **비밀번호나 개인정보 같은 민감한 내용은 입력하지 마세요.**
- 회원가입도, 저장 기능도 없습니다. 링크를 잃어버리면 새로 만들어야 해요.
